Nmap (Network Mapper)
- 내 컴퓨터에서 어떤 포트가 열려있는지 탐색하는 스캐닝 도구
- 보안 점검에서는 사용하지 않는 포트가 열려있는지 찾아봄(선제적인 보안 취약점 진단)

Npcap (Nmap packet capture)
- 컴퓨터를 오가는 데이터(패킷)를 직접 가로채서 전달하는 수집 엔진
- Nmap의 일부 검사와 Wireshark와 같은 분석 도구가 실시간 트래픽을 감시할 수 있도록 기반 제공

Wireshark
- 수집한 네트워크 데이터(패킷의 세부 내용)를 화면에서 자세히 살펴보는 도구
- 보안 점검에서는 접속 과정과 요청,응답에 이상한 점이 있는지 확인
- 해킹/악성코드 트래픽 추적 및 암호화되지 않은 민감 정보 노출 여부 점검

트래픽(Traffic)
-네트워크에서 컴퓨터들 사이에 오가는 데이터의 양이나 흐름
트래픽을 분석: 네트워크상에 오가는 데이터들을 관찰하여 이상 징후(해킹, 악성코드, 정보 유출 등)가 있는지 감시 하는것

<TCP 3-Way Handshake 과정>
1. SYN(Synchronize Sequence Numbers)
* 클라이언트 -> 서버
* "나랑 연결할래? 내 번호는 100번이야." 하고 연결 요청을 보냄

2. SYN-ACK (Synchronize-Acknowledgment)
SYN-ACK은 서버가 클라이언트의 연결 요청을 수락하면서, 동시에 자신도 통신할 준비가 되었음을 알리는 쌍방향 확인 신호
*서버 -> 클라이언트
* "어, 확인했어(ACK)! 네가 보낸 100번 잘 받았으니 다음엔 101번 보내줘. 그리고 나도 너랑 연결하고 싶어"
내 번호는 2000번이야(SYN)." 하고 응답.

3. ACK (Acknowlegment)
* 클라이언트 -> 서버
"나도 확인했어! 그럼 2001번 보낼게. 연결 시작하자!" 하고 최종 확정

*SYN은 연결 요청(Request), ACK는 확인 응답(Response)

netstat -ano | findstr :8081
=> TCP 127.0.0.1:8081 0.0.0.0:0 LISTENING pid표시(각자 다름)

netstat : 네트워크 연결 상태 표시

-n : 주소와 포트를 숫자로 표시
